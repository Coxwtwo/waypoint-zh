# Waypoint

### 夜空下的目标

*17 种经过验证的达成目标之法，集于一个免费应用。把梦想拆成大谷翔平的曼陀罗 64，用 OKR 跑一个季度，把一年压缩成 12 周，或者先试做某件事 30 天。每个目标都会变成一片星座，你迈出的每一步都会点亮一颗星。无广告、无账号、离线可用。*

## 理念

达成目标没有唯一正确的方式。跑马拉松需要的计划和学一门新语言不一样，而「我想改变生活」又另当别论。人们花了几十年发明各种方法：日本教练的 9×9 表格、英特尔的 OKR、心理学家的「如果—那么」计划。

Waypoint 把其中最优秀的都汇集到一处，逐一解释，并帮你挑选。一个目标由一种方法驱动，也可以借用其他方法的视角。无论用哪种方法，今天所有目标的步骤都会落在同一个屏幕上。

## 方法

| | 组 | 方法 |
|---|---|---|
| 🧭 | **选择目标** | 生命之轮 · 奥德赛计划 · 5/25 · 梦想清单 |
| 🔍 | **打磨它**（任何目标的视角） | SMART · WOOP · GROW · 五个为什么 |
| ✦ | **驱动它**（每个目标一个） | 曼陀罗 64 · OKR · 12 周完成一年工作 · 4DX · 每天 1% · 30 天约定 · 倒推计划 · 里程碑 |
| 🛡️ | **保护它** | 事前验尸 |

每种方法都附带说明、步骤和出处——就在你选择它的地方，以及它驱动的目标上。拿不准？「哪种方法适合我？」里的五个问题会推荐两个方法和一个视角。

## 包含什么

| | 功能 | 它是如何运作的 |
|---|---|---|
| ✦ | **曼陀罗 64** | 大谷翔平的表格化作星空图：目标居中、八根支柱、64 项行动。有些做成习惯，有些当成一次性步骤，行动成为你的一部分时点亮一颗星。可以把图表分享为海报。 |
| 🎯 | **OKR** | 一个目标、3–5 个带起点和目标值的关键结果、带历史曲线的检视、0–1 评分、你的信心，以及每个结果下的行动举措。 |
| 📅 | **12 周完成一年工作** | 每周战术、每周相对 85% 线的执行得分、愿景，以及开启下一年的第 13 周复盘周。 |
| 📈 | **4DX、改善、约定、倒推计划、里程碑** | 领先指标记分板、每天 1% 的曲线、30 星的约定（继续/暂停/转向）、从终点走回今天的阶梯、简单的里程碑与习惯。 |
| 💡 | **视角** | SMART 表述、带提醒的 WOOP「如果—那么」计划、GROW 选项、落到目标卡片上的五个为什么、对失败可能的事前验尸。 |
| 🌅 | **今天** | 一天一条航线，汇集所有目标的步骤：连续记录、+1 计数器和改善数字。备用航线在你偏离轨道时展示「如果—那么」计划。 |
| 🌌 | **星座** | 每个目标都有自己的形状。随着推进，星星逐一点亮，达成的目标留在日志里，化作一面星座墙。 |
| 📓 | **日志** | 每周复盘（什么进展顺利、什么挡了路、要改变什么、这一周感觉如何）、随时间的生命之轮、达成的目标和你放下的目标，以及它们教会你的东西。 |
| 🎚️ | **聚焦上限** | 选择同时可以激活多少个目标。其余在队列里等待，直到空出位置。 |

## English、Русский 和 中文

每个屏幕和每种方法指南都用英文、俄文和简体中文三种语言原生撰写。在 **设置 → 语言** 中切换；Android 13+ 上应用也会出现在系统的「应用语言」设置里。

## 下载

从 **[Releases](https://github.com/bigdevwhale/waypoint/releases/latest)** 获取 APK，或从任意 [CI 运行](https://github.com/bigdevwhale/waypoint/actions/workflows/android.yml) 附带获取 debug APK。Waypoint 需要 Android 8.0（API 26）或更高版本。

> [!TIP]
> 在小米（MIUI / HyperOS）、华为等部分手机上，请允许 **自启动** 并取消电池限制，这样早晨的航线、晚间检查和步骤提醒才能准时送达。

## 隐私

Waypoint 没有账号、服务器、分析、广告，也没有联网权限。目标、步骤、复盘和笔记都保存在手机上。**设置 → 备份** 把一切导出为一个 JSON 文件，由你保存。

## 技术实现

- **Kotlin + Jetpack Compose**，Material 3 配自研的夜空色板（以及黎明色板），字体用 Unbounded 和 Manrope。天空、星星和星座都画在 `Canvas` 上。
- **Room** 存储目标，以及一棵通用的步骤树：曼陀罗支柱、关键结果、12 周战术、领先指标和「如果—那么」计划都是不同种类的 `Node`。日日志、自由文本字段、复盘、生命之轮评估和工具条目补全了它。**DataStore** 保存设置。
- `domain/World` 承载共享规则：今天该做什么、连续记录、12 周得分、改善目标，以及每种方法的进度。测验打分是一个带单元测试的纯函数。

```
app/src/main/java/app/waypoint/
├── data/        Room 数据库、设置、JSON 备份、演示数据
├── domain/      方法、今天该做什么、连续记录、得分、进度
├── notify/      早晨航线、晚间检查、每周复盘、步骤提醒
├── widget/      主屏幕上的「今天的航线」
└── ui/          今天、目标、指南针、日志、8 种方法、5 个视角、4 种工具、测验
```

用 `./gradlew assembleDebug` 构建。`./gradlew installDebug -Pdemo` 会安装 `app.waypoint.demo`，带编造的目标——这些截图就是用它的。
